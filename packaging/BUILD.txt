# Windows Screenshot Monitor packaging
# Updated 2026-10-06. Installers already exist; this is no longer a future Phase 7 note.
#
# Build on Windows 64-bit from the repository root:
#   py -3 -m pip install -r requirements.txt pyinstaller
#   py -3 -m PyInstaller packaging/client.spec
#   py -3 -m PyInstaller packaging/server.spec
# Output:
#   dist/ScreenshotClient.exe
#   dist/ScreenshotServer.exe
#
# Installers:
#   packaging/client.iss
#   packaging/server.iss
# Compile with Inno Setup on Windows. Both scripts require x64-compatible mode.
# Do not run the repository-root install.bat. That file is the old TorCap installer.
#
# Installed layout:
#   C:\Program Files\Windows Screenshot Monitor\Client
#   C:\Program Files\Windows Screenshot Monitor\Server
# Runtime files are not stored beside the executable.
# Client config and cache use C:\ProgramData\ScreenshotClient.
# Server config, retention state, and install manifest use C:\ProgramData\ScreenshotServer.
# Logs are created on each process start under the current user's Documents folder:
#   Documents\ScreenshotClient\Logs\YYYYMMDD_HHMMSS_CC.LOG
#   Documents\ScreenshotServer\Logs\YYYYMMDD_HHMMSS_CC.LOG
# Uninstall does not delete Documents logs.
# Application data is only deleted if the uninstall prompt is accepted.
