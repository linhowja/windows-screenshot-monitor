# Windows packaging foundation. Installers come in the next Phase 7 commit.
# Run from the repository root on Windows 64-bit:
#   py -3 -m pip install -r requirements.txt pyinstaller
#   py -3 -m PyInstaller packaging/client.spec
#   py -3 -m PyInstaller packaging/server.spec
# Output:
#   dist/ScreenshotClient.exe
#   dist/ScreenshotServer.exe
# Runtime files are not stored beside the executable.
# Client config and cache use C:\ProgramData\ScreenshotClient.
# Server config uses C:\ProgramData\ScreenshotServer.
# Logs are created on first launch under the current user's Documents folder:
#   Documents\ScreenshotClient\Logs\YYYYMMDD_HHMMSS_CC.LOG
#   Documents\ScreenshotServer\Logs\YYYYMMDD_HHMMSS_CC.LOG
# Installers do not create ProgramData\Logs, and uninstall does not delete Documents logs.
